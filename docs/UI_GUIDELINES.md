# إرشادات واجهة المستخدم

## الاتجاه والنص
- الاتجاه: RTL (يمين لليسار)
- اللغة الأساسية: العربية
- الخط: Cairo (Google Fonts)

## لوحة الألوان
- **الأساسي:** #2563eb (أزرق)
- **الثانوي:** #64748b (رمادي)
- **النجاح:** #16a34a (أخضر)
- **الخطر:** #dc2626 (أحمر)
- **التحذير:** #d97706 (برتقالي)
- **الخلفية:** #f8fafc
- **الشريط الجانبي:** #1e293b

## التخطيط
- شريط جانبي ثابت (260px)
- رأس الصفحة علوي ثابت (64px)
- منطقة المحتوى الرئيسية قابلة للتمرير

## المكونات الأساسية
- بطاقات الإحصائيات: ظل خفيف، أيقونة ملونة
- الجداول: Bootstrap table-hover، zebra striping
- النماذج: validation فوري، رسائل خطأ واضحة
- التنبيهات: toast notifications في الزاوية
- الأزرار: primary/secondary/danger/success

## حالات النظام (Badges)
- مسودة: رمادي
- نشط/مرسل: أزرق
- مقبول/مدفوع: أخضر
- مرفوض/ملغي: أحمر
- منتهي/متأخر: برتقالي
