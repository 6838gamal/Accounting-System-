# وصف الوحدات

## الوحدات الرئيسية

### 1. وحدة المصادقة (Auth)
**المسارات:** `/auth/login`, `/auth/logout`
**المهام:** تسجيل الدخول والخروج، إدارة الجلسات، التحقق من الصلاحيات

### 2. لوحة التحكم (Dashboard)
**المسار:** `/dashboard`
**المهام:** عرض الإحصائيات والرسوم البيانية والتنبيهات

### 3. المستخدمون (Users)
**المسارات:** `/users/*`
**المهام:** CRUD المستخدمين، إدارة الأدوار والصلاحيات

### 4. العملاء (Clients)
**المسارات:** `/clients/*`
**المهام:** CRUD العملاء، البحث والتصفية، سجل العميل

### 5. العقود (Contracts)
**المسارات:** `/contracts/*`
**المهام:** CRUD العقود، إدارة الحالات، التحويل إلى فاتورة

### 6. عروض الأسعار (Quotations)
**المسارات:** `/quotations/*`
**المهام:** CRUD العروض، التحويل إلى عقد/فاتورة، PDF

### 7. الفواتير (Invoices)
**المسارات:** `/invoices/*`
**المهام:** CRUD الفواتير، البنود، الضرائب، PDF، الطباعة

### 8. المدفوعات (Payments)
**المسارات:** `/payments/*`
**المهام:** تسجيل المدفوعات، تتبع حالة الفواتير

### 9. المصروفات (Expenses)
**المسارات:** `/expenses/*`
**المهام:** تسجيل المصروفات، الموافقة، التصنيف

### 10. التقارير (Reports)
**المسارات:** `/reports/*`
**المهام:** تقارير متعددة، تصدير PDF/Excel

### 11. الإعدادات (Settings)
**المسار:** `/settings`
**المهام:** إعدادات الشركة، الضرائب، العملة، الترقيم

### 12. سجل العمليات (Activity Log)
**المسار:** `/activity-log`
**المهام:** عرض وبحث سجل جميع العمليات
