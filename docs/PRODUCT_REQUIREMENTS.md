# متطلبات المنتج

## الوحدات الوظيفية

### 1. نظام المستخدمين والصلاحيات
- تسجيل دخول/خروج آمن
- أدوار: Admin, Manager, Accountant, Viewer
- إدارة المستخدمين (CRUD)
- تعيين الصلاحيات على مستوى الوحدة
- تأمين الجلسة وانتهاء صلاحيتها

### 2. لوحة التحكم
- إجمالي الإيرادات (الشهر الحالي/السابق)
- عدد الفواتير المعلقة
- عدد العملاء النشطين
- أحدث 5 فواتير
- أحدث 5 عقود
- رسم بياني للإيرادات (12 شهر)
- رسم بياني للمصروفات
- تنبيهات الفواتير المتأخرة

### 3. إدارة العملاء
- إضافة/تعديل/حذف/عرض
- بحث وتصفية
- ملف العميل الكامل (عقوده، فواتيره، مدفوعاته)
- تصنيف (شركة/فرد)
- ملاحظات ومرفقات

### 4. إدارة العقود
- إنشاء عقود مرتبطة بالعملاء
- حالات: مسودة، نشط، منتهي، ملغي
- تواريخ البداية والنهاية
- تحويل العقد مباشرة إلى فاتورة
- مرفقات العقود

### 5. عروض الأسعار
- إنشاء عروض مفصلة بالبنود
- حالات: مسودة، مرسلة، مقبولة، مرفوضة
- تحويل إلى عقد أو فاتورة مباشرة
- تصدير PDF

### 6. الفواتير
- إنشاء فواتير ببنود متعددة
- الضريبة المضافة والخصومات
- حالات: مسودة، مرسلة، مدفوعة جزئياً، مدفوعة، متأخرة
- تصدير PDF وطباعة
- ربط بالمدفوعات

### 7. المدفوعات
- تسجيل مدفوعات الفواتير
- طرق الدفع: نقداً، تحويل، شيك، بطاقة
- سجل كامل لكل فاتورة
- تنبيهات الدفعات المتأخرة

### 8. المصروفات
- تسجيل المصروفات بالفئات
- رفع إيصالات
- موافقة المدير
- تقارير المصروفات الدورية

### 9. التقارير
- تقرير المبيعات (يومي/شهري/سنوي)
- تقرير العملاء (أعلى عملاء)
- تقرير الفواتير
- تقرير الأرباح والخسائر
- تقرير المصروفات
- تصدير PDF وExcel

### 10. الإعدادات
- بيانات الشركة (اسم، شعار، عنوان)
- إعدادات الضريبة الافتراضية
- عملات النظام
- ترقيم الفواتير
- إعدادات البريد الإلكتروني

### 11. سجل العمليات
- تسجيل كل إجراء (إنشاء/تعديل/حذف)
- مع بيانات المستخدم والوقت
- بحث وتصفية
- تصدير السجل

## المتطلبات غير الوظيفية
- الأداء: استجابة أقل من 500ms للصفحات العادية
- الأمان: تشفير كلمات المرور، CSRF protection، XSS prevention
- الاستجابة: يعمل على سطح المكتب والأجهزة اللوحية
- دعم اللغة العربية (RTL)
