الهدف من الأخطاء
==================================================

Internal Errors

Python Errors

Database Errors

File Paths

Secrets

Environment Variables

أريد رسائل احترافية مثل:

  "success": false,
  "message": "حدث خطأ غير متوقع، يرجى المحاولة لاحقًا.",

}

بينما يتم تسجيل الخطأ الحقيقي في الـ Logs فقط.

==================================================
النتيجة المطلوبة
==================================================

لا تعطني تقريرًا فقط.

بل نفذ التالي:

1- اذكر المشكلة.

2- لماذا هي خطيرة.

3- كيف استغلها المهاجم.

4- مستوى الخطورة:

Critical

High

Medium

Low

5- اكتب الكود الجديد.

6- اذكر مكان وضعه.

7- اذكر الملف.

8- اذكر سبب اختيار الحل.

9- إذا كان هناك أكثر من حل فقارن بينها.

10- لا تنتقل للنقطة التالية حتى يتم إصلاح السابقة بالكامل.
